# Start MoDL Server
## Description
Starts MoDL Server locally to allow fast calling MoDL  segmentation without relaunching Python environment for every image (sets).
Start MoDL Server once in a session when you start to work, and leave the command window open as long as it is needed. 
To stop MoDL Server, close the command window.

The server will be available at: http://localhost:5002/segment

API fields:
--dir
--weights
--model
--overlap
--scale
--threshold
--batch-size
--output-original-size
