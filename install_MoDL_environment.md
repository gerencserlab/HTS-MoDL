# Install MoDL Environment
## Description
Run this pipeline once to install environment and dependencies for MoDL
Python 3.10 must be installed on the system for this (install from python.org).
Image Analyst may need to be run as administrator to do this.
CUDA 11.8 and CUDNN 8 need to be installed an added to PATH to use GPU - see README.md
